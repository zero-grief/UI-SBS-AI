# README

## Så använder du filen

Det här dokumentet är tänkt att användas tillsammans med den bifogade `.md`-filen som styrdokument för ett hemsideprojekt.

### 1. Starta en ny chat
Använd filen i en ny konversation där fokus bara är hemsideprojektet.

### 2. Bifoga `.md`-filen direkt i chatten
Filen fungerar som ett styrdokument för hela arbetsprocessen.

### 3. Be agenten läsa hela dokumentet först
Det är viktigt att agenten först förstår helheten innan något designarbete börjar.

### 4. Agenten ska sedan följa stegen i ordning
Arbetsflödet är tänkt att gå så här:

1. först läsa guiden i sin helhet  
2. sedan be dig bifoga befintliga eller tänkta assets  
3. därefter be om din beskrivning och vision för hemsidan  
4. sedan analysera referenserna  
5. därefter ta fram mockup, wireframe blueprint och komplett UI-kit  
6. till sist sammanställa allt i ett tydligt arkiv med dokumentation  

### 5. Använd filen som arbetsgrund, inte bara som prompt
Det här dokumentet är inte tänkt som en engångsfråga utan som en tydlig arbetsplan för hela designprocessen.

### 6. Bifoga gärna referensmaterial samtidigt
Logotyper, knappar, paneler, bakgrunder, zip-filer, screenshots och liknande hjälper agenten att hålla rätt riktning från början.
